### Klepto-mania:

is a 2D puzzle game that has only one character, Bachira. 

Bachira is addicted to stealing so even though he knows that what he do hurts his mother he can't help himself. so we'll help him not get caught.



We'll complete all 5 puzzles in a strict sequence that will be shown in the game as hints. trying to attempt a further puzzle before the previous one will not work so the player has to follow the rules. 



**Tasks**

1. **Light candles:** 

2. **Find the Right Key**

3. **Pick up the blue duck**

4. **Audio puzzle**

5. **Enter the correct code to unlock the door**





**ASSETS**

All my assets where fetched from "https://assetstore.unity.com/"

Bachira animation was done by me 

and a picture from "https://www.pinterest.com/"





**Controls explanation** 

use: Left, right, up, down keys or WASD
E to interact with everything except Ducks

Ducks use B 

and space tab to enter the unlock door code
